# PinDock

[简体中文](README.md) | [English](README_EN.md)

Windows 独立快捷启动工具。提供现代化悬浮 Dock、目录多级悬停预览、收藏分组、托盘快捷浮窗与主题定制，与系统原生任务栏共存。

## 核心特性 (v0.1.6)

- **混合渲染架构（C# .NET 10 + WebView2 HTML/CSS）**
  - 系统底层（全局热键、48×48 高清系统图标提取、全屏应用避让、资源管理器右键、开机自启、单实例 IPC）采用 C# 原生实现；
  - 《全部收藏》《设置》《添加/编辑收藏》《配置分组》面板采用预热 WebView2 硬件加速渲染（[Assets/ui.html](src/PinDock/Assets/ui.html)）。
- **悬浮 Dock 与高度可定制布局**
  - **四边停靠 & 三种呼出模式**：支持常驻显示、全局快捷键呼出（可自定义录制或清除）、贴边自动隐藏（支持拖拽文件靠近屏幕边缘自动唤醒）；
  - **纯图标 / 图标 + 文字双模式**：支持 macOS 式纯图标显示与手机桌面式「上图标 + 下方居中标题」显示，可在设置页或 Dock 右键菜单一键切换；
  - **拖拽排序与自定义分隔符**：直接在 Dock 上拖拽图标/分组/分隔符即可调整顺序；按住空白边框或 `Alt + 拖拽` 移动 Dock 整体位置；支持右键插入/删除分隔符或一键按「应用 / 文件夹 / 分组」自动分隔；
  - **右侧功能抽屉开关 (`‹ / ›`)**：Dock 末端提供紧凑折叠开关，一键展开或收起「全部收藏」「＋添加」「⚙设置」功能按钮。
- **全面自定义图标体系（应用 / 文件夹 / 收藏组）**
  - 所有单个收藏项与收藏组均支持自定义图标：**默认系统/文件夹图标**、**内置分类矢量图标（磁盘分区、项目目录、开发工具、硬件芯片、命令行、办公资料、数据文档等）**、**字母/数字徽标图标（A–Z、0–9 或自定义 1~3 字符）**、**本地图片或程序图标 (`.png / .ico / .jpg / .exe / .lnk`)**；收藏组还额外支持 **组内前 4 项 `2×2` 微缩宫格图标**。
- **文件夹悬停预览与智能目录浏览**
  - 鼠标悬停在 Dock 上的文件夹或磁盘图标即可弹出多级目录快速浏览面板，支持面板内下钻展开、关键字搜索、一键固定子目录；
  - **长目录/文件全名智能展示**：悬停行上方即时弹出多行完整名称卡片（含类型、文件大小与修改/创建时间，支持上下连续零延迟扫读），底部状态栏 0 延迟联动显示全名，并支持右键一键复制完整名称或路径；
  - **丝滑多目录切换体验**：内置首屏极速分批渲染、目录枚举缓存与扩展名级图标共享缓存，左右快速滑过多个文件夹预览零卡顿；
  - **5 种目录排序与独立记忆**：支持按名称 (`A→Z` / `Z→A` 自然数字排序)、修改时间（最新/最早）、创建时间（最新）排序，自动为每个目录独立记忆排序偏好，并在时间排序下显示修改/创建日期；
  - **隐藏与恢复指定子文件夹**：支持悬停或右键隐藏不需要展示的子文件夹，底部状态栏可随时查看并一键恢复已隐藏目录。
- **右下角托盘左击快捷浮窗（Flyout）**
  - 左击系统托盘图标弹出近托盘快捷中心，集成：顶部即时搜索框（回车直接启动）、亮暗主题与中英文快切、Dock 状态快捷控制栏、最近使用栏、固定项与分组分类速览、底部工具栏（支持直接拖入文件/文件夹添加）。
- **中英文双语与快速主题切换**
  - 支持 `简体中文 (zh-CN)` 与 `English (en-US)` 全界面实时切换；
  - 内置 5 套现代配色（苔原绿、海盐蓝、暖砂、陶土、石墨）× 浅色/深色/跟随系统，面板顶部、托盘浮窗与 Dock 右键均支持 `☀ / 🌙` 一键切换亮暗主题。
- **Windows 11 右键集成与在线升级**
  - 支持所有文件/应用、文件夹、目录背景、磁盘驱动器右键“添加到 PinDock”及系统 `SendTo`（发送到），并提供 **Windows 11 一级右键菜单直显** 开关；
  - 支持开机自动启动、关闭面板隐藏到托盘或直接退出；
  - 内置 GitHub Releases 在线检查更新与一键覆盖升级，支持**国内镜像加速开关与自定义镜像源**。

## 运行与编译安装包

需要 Windows 10/11 和 .NET 10 SDK：

```powershell
# 编译与运行自动化测试
dotnet build PinDock.sln
dotnet run --project tests/PinDock.Tests

# 启动开发版
dotnet run --project src/PinDock

# 一键编译生成安装包 (输出至 dist\PinDock-Setup-0.1.6.exe)
powershell -ExecutionPolicy Bypass -File scripts\build-installer.ps1
```

收藏与设置保存在 `%LocalAppData%\PinDock\library.json`（移除收藏不会删除目标文件）。版本更新记录见 [CHANGELOG.md](CHANGELOG.md)。
