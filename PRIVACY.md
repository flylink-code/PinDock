# PinDock 隐私政策 / Privacy Policy

**生效日期 / Effective Date:** 2026-10-29

## 中文说明

**PinDock** 是一款完全运行于用户本地计算机的 Windows 桌面快捷启动工具。我们高度重视您的隐私：

1. **无个人数据收集**：PinDock 不包含任何账号体系、遥测统计（Telemetry）、行为追踪或广告 SDK，不会收集、上传或共享您的任何个人信息、文件列表或使用习惯。
2. **本地数据存储**：您配置的所有应用路径、文件夹书签、分组与界面设置均仅保存在您本机的 `%LocalAppData%\PinDock\library.json` 文件中，完全由您自行控制与备份。
3. **按需网络访问**：PinDock 在日常运行中完全离线工作。仅当您在「设置 -> 数据与关于」中主动点击「检查更新」时，程序才会请求 GitHub Releases 公开接口获取最新版本号与安装包下载链接。

---

## English Version

**PinDock** is a standalone desktop launcher utility that runs locally on your Windows PC. We take your privacy seriously:

1. **Zero Data Collection**: PinDock contains no user accounts, telemetry, analytics, tracking, or advertising SDKs. It does not collect, transmit, or share any personal information, file paths, or usage history.
2. **Local Storage Only**: All bookmarks, folder shortcuts, groups, and user preferences are stored exclusively on your local device at `%LocalAppData%\PinDock\library.json`.
3. **On-Demand Network Access**: PinDock operates completely offline during normal use. It only makes a network request to the public GitHub Releases API when you explicitly click "Check Update" in the Settings panel.
